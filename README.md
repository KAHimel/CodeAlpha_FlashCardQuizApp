# Flash Card Quiz App

A simple Flutter flashcard quiz application for creating, reviewing and managing study cards.

## 📱 Features

✅ Question and answer flashcards

✅ Show/hide answer toggle

✅ Next and previous navigation between cards

✅ Add, edit, and delete flashcards

✅ Clean and responsive Material UI

✅ Card management sheet for easy customization

---

## 🛠️ Technologies Used

* Flutter
* Dart

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/KAHimel/CodeAlpha_FlashCardQuizApp.git
```

### 2. Navigate to the project folder

```bash
cd CodeAlpha_FlashCardQuizApp
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```

---

## 🎯 App Overview

This app is designed for learners who want a lightweight, customizable flashcard experience.

* View one flashcard at a time
* Flip cards to reveal answers
* Move through cards with Previous and Next buttons
* Manage cards from the top-right card manager
* Add new study cards, edit existing cards, and delete cards as needed

---

## 📄 Notes

* This is a UI-focused Flutter app with local in-memory card storage.
* There is no backend or persistent storage implemented.
* The app is ideal for building a study set and reviewing flashcards quickly.
